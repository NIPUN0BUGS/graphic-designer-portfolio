# Graphic Designer Portfolio

Responsive static portfolio website for Nipun Samarakoon.

## Run locally
Open `index.html` in a browser. No build step or dependencies are required.

## Add more projects
1. Copy the new image into `assets/`.
2. Duplicate a `<article class="project-card">` block in `.project-grid` in `index.html`.
3. Update the image paths, alt text, title, description, number and `data-category`.
4. Categories: `advertising`, `events`, `education`, `branding`.

## Update contact details
Replace the placeholder `mailto:` link in the contact section with your professional email. Add LinkedIn and WhatsApp details when ready.

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Files
- `index.html` page content
- `styles.css` responsive styling
- `script.js` gallery filters, mobile menu and image preview
- `assets/` design samples
